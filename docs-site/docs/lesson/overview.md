# 体験型授業 概要

!!! note "自動運転の3ステップ"
    **認知（超音波センサー/カメラ等）→ 判断（モードの選択/紹介）→ 操作（モーター出力）** の順で自動運転を実施

---

## 使用するハードウェア

- Raspberry Pi 4/5 または Jetson Orin Nano
- モーター（ESC制御）+ ステアリングサーボ
- 超音波センサー（HC-SR04）またはLiDAR
- カメラモジュール
- ゲームコントローラー（Logicool F710など）

## 学習目標

1. センサーから環境情報を取得する方法を理解する
2. 取得した情報から走行判断を行うロジックを学ぶ
3. 判断結果をモーター制御に変換する仕組みを習得する
4. 自分で走行ルールをカスタマイズできるようになる


## 各セクション

### [認知](recognition.md)
- 超音波センサーの仕組みと特性
- カメラ画像の取得
- センサーの違いと使い分け

### [判断](decision.md)
- 走行モードの選択
- ルールベース vs ニューラルネットワーク
- アルゴリズムの理解

### [操作](control.md)
- PWM信号の基本
- 制御値から動きへの変換
- フィードバック制御
