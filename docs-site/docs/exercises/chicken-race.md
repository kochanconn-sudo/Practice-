# チキンレース！壁に直前で止まろう

壁にぶつかる直前で停止する「チキンレース」に挑戦します。パラメータ調整で停止距離を最適化しましょう。

## 目標

- 壁にできるだけ近づいて停止する
- ぶつからないギリギリを狙う
- パラメータ調整の基本を学ぶ

## config.py設定

```python
# モーター出力パラメータ （-1~1で設定）
# スロットル用
FORWARD_S = 0.6   # ストレートでの値, joy_accel1
FORWARD_C = 0.4   # カーブでの値, joy_accel2
REVERSE = -1

# 復帰モード選択
RECOVERY_MODE = "back"            # none, back
RECOVERY_STREERING = LEFT         # 復帰時のステアリング値
RECOVERY_TIME_DURATION = 1        # 復帰処理を行う時間（秒）
RECOVERY_BRAKING = 1              # ブレーキ回数、ブレーキにはREVERSEの値を利用
```

## 調整するパラメータ

### 停止距離（STOP_RANGE）

```python
STOP_RANGE = 100  # mm単位
```

- 値を小さくする → より壁に近づいてから停止
- 値を大きくする → 早めに停止（安全）

### 速度（FORWARD_S / FORWARD_C）

```python
FORWARD_S = 0.6   # 直線での速度
FORWARD_C = 0.4   # カーブでの速度
```

- 速度が速いほど停止距離が長くなる
- 慣性を考慮した設定が必要

## やってみよう！

### ステップ1: 基本設定で走行

1. デフォルト設定で走行開始
2. 停止位置と壁との距離を測定
3. 記録する

### ステップ2: STOP_RANGEを調整

1. `STOP_RANGE`を10mm単位で調整
2. 走行して停止位置を確認
3. 最適な値を探す

### ステップ3: 速度を変えてテスト

1. `FORWARD_S`を変更（0.4〜0.8）
2. 同じ`STOP_RANGE`で走行
3. 速度と停止距離の関係を観察

## ヒント

!!! tip "最適化のコツ"
    - 同じ条件で複数回テストして平均を取る
    - 床の材質によって滑りやすさが変わる
    - バッテリー残量で速度が変わることがある

!!! warning "安全注意"
    - 最初は安全なパラメータから始める
    - 壁にクッション材を置いて衝撃を吸収
    - 周囲に人がいないことを確認
